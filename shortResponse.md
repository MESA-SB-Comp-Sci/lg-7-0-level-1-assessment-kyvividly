## Question 1 — Describe

What is the difference between a static unit like `px` and a responsive unit like `%` or `vh`?

'px' makes it so whatever number you put in is what it stays no mattter the device while '%' or 'vh' makes it so that number isn't fixed; it adjusts automatically to the device and the size of the browser.

Describe what makes a unit responsive and why that matters when building a website.

A unit is responsive when it isn't fixed, it reacts to certain things like type of device, browser size, etc. 'vh, vw' and '%' count since they change based on what else changed. This matters when making a website for organized and well-designed layouts, or just makes the website look better in general.

## Question 2 — Explain

Look at these two CSS rules:

```css
.image {
  width: 400px;
}

.image {
  width: 50%;
}
```

Explain what happens to the image on a small screen with each rule. Why does one behave better than the other?



On a small screen, the first .image class stays 400px and looks awkward on a small device like a phone, while the second one adjusts to the device. The second is better since it allows for better looks & design.
